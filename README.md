# Colores de Fondo - HTML5 & CSS3

Este proyecto consiste en replicar una maqueta utilizando **HTML5** y **CSS3**, aplicando diferentes colores de fondo y organizando los elementos en una cuadrícula similar a la imagen de referencia.

## Objetivo

Reproducir el diseño respetando la distribución de los bloques, los colores, la tipografía y el espaciado mediante HTML5 y CSS3.

## Tecnologías utilizadas

- HTML5
- CSS3

## Características

- Estructura semántica con HTML5.
- Bloques con diferentes colores de fondo.
- Maquetación mediante CSS Grid o Flexbox.
- Diseño limpio y adaptable a distintos dispositivos.
